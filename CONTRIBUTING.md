# Contribuindo

Contribuições são bem-vindas via Pull Request no [GitHub](https://github.com/kevind3v/brlayer).

- **Testes**: toda mudança de comportamento vem com teste. Rode `composer test` (veja "Testes" no README).
- **Padrão de código**: [PSR-12](https://www.php-fig.org/psr/psr-12/).
- **Documente mudanças de comportamento** no README.
- **Um Pull Request por funcionalidade**, a partir de uma branch própria.
